**Kiln** is a free, open-source Second Life viewer with modeling and texture painting built in: shape, glaze and fire your work without leaving the world.

It is built on Linden Lab's official viewer, follows its releases, and runs beside Firestorm or the official viewer.

### What's here

| Repository | What it is |
|---|---|
| **kiln-viewer** | The viewer itself (LGPL-2.1). Opens to the public with the first preview. |
| [kiln-data](https://github.com/kiln-viewer/kiln-data) | Release data the viewer reads at startup: latest version and blocked versions. |
| [kiln-viewer.github.io](https://github.com/kiln-viewer/kiln-viewer.github.io) | The website, [kilnviewer.com](https://kilnviewer.com). |
| [.github](https://github.com/kiln-viewer/.github/tree/main/brand) | This profile and the brand kit: icon, logo, colours, type. |

### Status

In development. Mesh editing and texture painting come first; UV editing, LOD and physics generation, local preview before upload and a Blender link follow. Watch this organisation to hear when the first preview is ready.
