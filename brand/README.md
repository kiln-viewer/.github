# Kiln brand kit

## Name

**Kiln**, or **Kiln Viewer** where the context needs it. Never "Second Life Kiln", "SL Kiln" or anything else using Linden Lab marks (Third Party Viewer Policy).

Tagline: *The Second Life viewer with a studio inside.*
Short line: *Shape it. Paint it. Fire it in-world.*

## Files

| File | Use |
|---|---|
| `icon.png` | App icon, rounded tile with transparent corners, 1024 px. Windows, Linux, web. |
| `icon-fullbleed.png` | Square, no corners, 1024 px. macOS 26 asset catalogs and anything that applies its own mask (avatars, app stores). |
| `avatar.png` | 500 px profile picture for GitHub, Discord, Second Life groups. |
| `logo-horizontal.svg` | Icon and wordmark side by side, for light-on-dark use. |
| `social.png` | 1280 × 640 link preview (GitHub social preview, Open Graph). |
| `banner.png` | 1280 × 400 header for profiles and READMEs. |

The icon source and the script that builds every viewer icon from it live in the viewer repository under `kiln/branding/`.

## Colour

| Role | Hex | Where |
|---|---|---|
| Ground | `#120b09` | Page and app background |
| Tile | `#1e1411` | Surfaces one step up |
| Ink | `#eeebe8` | Text on dark |
| Ink, dark | `#1a0e0a` | Text on light and on flame |
| Clay, light | `#e6d8c6` | The name band, light fields |
| Clay | `#b9a088` | Secondary fields |
| Glaze | `#2bb3a6` | Highlights, links on dark |
| Glaze, deep | `#136e69` | Deep fields |
| Flame | `#ff6a2a` | The one action on a screen |

Flame is the accent: one action per screen, nothing else.

## Type

[Jost](https://fonts.google.com/specimen/Jost) for everything. Display: weight 700, uppercase, tracking −0.03 to −0.04 em, leading 0.9. Text: weight 400, emphasis 500, leading 1.5.

## Don'ts

No gradients, glows or drop shadows behind the icon. Don't recolour the icon, stretch it, or set it on a busy photo without a solid tile behind it.
